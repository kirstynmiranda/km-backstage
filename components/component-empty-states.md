# Empty States — Component Rules

## Structure
Title + Body text + Primary CTA (optional but recommended) + Secondary CTA (optional)

## Title
- Let the user know what to do here or what this space is for.
- Sentence case. No period.
- Aim ≤ 30 chars; hard max 45.

## Body text
- Explain why empty, or what they can do here (supports title, doesn't repeat it).
- Include: what's true now / what happens after action / most helpful next step.
- Keep specific and local — don't advertise other areas of the app.
- Pick one path (don't list multiple options unless UI supports two distinct actions).
- Use a period at the end of sentences; avoid fragments with no end punctuation if full sentence.
- No ellipses. No exclamation marks.
- Aim ≤ 120 chars; hard max 180.

## Primary CTA (optional but recommended)
- Verb + object. "Browse items", "List an item".
- Aim ≤ 20 chars; hard max 28.

## Secondary CTA (optional)
- Only when meaningfully different from the primary.
- "Learn more" and similar = tertiary; present as hyperlinked text, not a button.

## Types

| Type | When | Goal | Structure |
|------|------|------|-----------|
| First-use / educational | Feature never used | Explain how to start + value | Title + 1 value sentence + 1 CTA |
| Zero results | Search / filters returned nothing | Help recover fast | Title + adjustment guidance + recovery CTA |
| Cleared data | User removed previously populated items | Confirm and orient | Title + short explanation + optional CTA |
| Waiting / time-based | Nothing to show yet (pending) | Set expectations | Title + when content will appear + optional CTA |
| Personalised content N/A | Not enough signals | Explain how to unlock | Title + "how to improve results" + CTA |
| Looks empty but is error | Network/server failure | Enable retry | Title + simple cause + retry CTA |

## Voice & tone
- Direct, helpful, non-judgmental.
- No seller-like pressure ("Buy now", "Hurry").
- More joyful Vinted tone can be introduced in low-risk first-use states to introduce functionality.
- Avoid cuteness that reduces clarity.

## ❌ Banned terms & patterns

| Avoid | Why |
|-------|-----|
| "Oops", "Uh-oh", "Whoops" | Tone over clarity |
| "Nothing here" / "No data" | Too vague |
| "Please" | Adds a word without clarity |
| "Try again later" (if avoidable) | Use a specific next step instead |
| "OK" as the only action | Doesn't help users move forward |
| "Shop now", "Don't miss out" | Salesy; wrong tone for empty states |

## ✅ Examples

| Type | Title | Body | CTA |
|------|-------|------|-----|
| First-use | Save your favourites | Hit the heart to save items you like and keep track of them here. | Browse items |
| Zero results | No items found | Try removing filters or searching for something else. | Clear filters |
| Cleared | No recently viewed items | Items you view will appear here. | Browse items |
| Waiting | Waiting for updates | Tracking updates appear when the carrier scans the parcel. | View order |
| Error | Can't load items | Check your connection and try again. | Try again |
