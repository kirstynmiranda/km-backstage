# Dialogs, Sheets & Covers — Component Rules

## Structure
Title + Body copy + Button(s)

## Title
- Specific; focus on the outcome.
- Prefer statements over questions.
- Avoid "Are you sure?" and other ambiguous titles.
- Follow with a capital letter if a complete sentence follows a colon.
- ≤ 48 characters.

## Body copy
- Complements the title; adds essential context.
- Lead with the most important detail or consequence.
- If irreversible, say so explicitly.
- 1–2 short sentences. ≤ 200 characters.

## Buttons
- Verbs that describe the outcome. Primary button verb matches the title verb.
- Sentence case. No end punctuation.
- Avoid Yes/No unless it genuinely clarifies an ambiguous action.
- Tertiary actions as hyperlinked text below buttons ("Learn more").
- ≤ 20 characters each.

## ❌ Do not use

| Element | Banned |
|---------|--------|
| Titles | "Are you sure?" |
| Buttons | Yes / No (unless genuinely clarifies ambiguity) |
| Cancel button when title says "Cancel" too | Use "Keep editing" instead |

## ✅ / ❌ Examples

| Dialog type | ✅ Good | ❌ Bad | Why |
|-------------|---------|--------|-----|
| Destructive confirmation | Title: "Delete listing?" / Body: "This will remove your listing and its messages. You can't undo this." / Buttons: Delete listing / Keep listing | Title: "Are you sure?" / Body: "This action cannot be undone." / Buttons: Yes, No | Good: specific + consequence + outcome-based buttons. Bad: vague, no context, ambiguous labels. |
| Unsaved changes | Title: "Discard changes?" / Body: "You have unsaved edits. You'll lose them if you leave now." / Buttons: Discard changes / Keep editing | Title: "Are you sure?" / Body: "Changes may not be saved." / Buttons: Leave, Stay | Good: names the risk. Bad: hedging language, unclear outcomes. |
| Onboarding (cover dialog) | Title: "Sell faster with Vinted" / Body: "List in minutes and reach millions of buyers." / Buttons: Get started / Maybe later | Title: "Welcome!" / Body: "Experience the best features. Click OK to continue." / Buttons: OK | Good: clear value prop, respectful opt-out. Bad: vague, coercive, ambiguous OK. |
