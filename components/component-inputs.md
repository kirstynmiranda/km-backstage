# Inputs & Input Bars — Component Rules

## Structure
Title + Placeholder + Helper (optional) + Validation(s)

## Title (label)
- Short, specific noun. No colon. No verb.
- "Email address", not "Enter your email:" 
- Required fields: mark with "(required)" if most are optional.
- Optional fields: mark with "(optional)" if most are required.
- Be specific where scope matters: "Delivery address" not "Address".
- Multi-part inputs: label each part separately.
- Aim ≤ 28 chars; hard max 40 (2 lines max).

## Placeholder
- Example-format only — not instructions.
- "name@example.com", not "Enter your email address here".
- No verbs. No full stops on fragments. No ellipses.
- Don't repeat or replace the label.
- No brand names as examples (not "e.g., Zara denim jacket").
- Use neutral fake data for sensitive fields ("name@email.com", not a real address).
- Aim ≤ 45 chars; hard max 60.

## Helper text
- Requirements and constraints that must stay visible while typing.
- Format rules, character limits, what to include, key policies.
- Never repeat validation message content.

## Validation
- Field name + what's wrong + how to fix it. One line.
- No blame. No jargon. No "to continue" (redundant).
- Validate as user types (when confident); otherwise on submit.
- ≤ 80 characters.

## Input bars (search)
- Global search: "Search" or "Search items"
- In-context: "Search in [area]" e.g. "Search favorites"
- Category: "Search [noun]" e.g. "Search brands"
- No ellipses. No ending punctuation.

## ❌ Banned terms

| Don't use | Where | Use instead |
|-----------|-------|-------------|
| Enter your… / Type your… | Labels, placeholders | Just the label noun; example in placeholder |
| Please… | Placeholders, errors | Omit |
| …to continue | Error messages | Omit entirely |
| Label + colon (:) | Titles | No colon |
| Ellipsis (…) | Placeholders | Use a specific example |
| Choose… (in forms) | Titles, placeholders | Select |
| Real personal data | Placeholders | Neutral fake data |

## ✅ / ❌ Examples

| Field | ✅ Good title | ✅ Good placeholder | ❌ Bad title | ❌ Bad placeholder |
|-------|-------------|-------------------|------------|-----------------|
| Email | Email | name@domain.com | Electronic mail address | Enter your email so we can contact you |
| Item description | Description | Warranty, accessories, previous repairs, any defects | Describe your item | E.g. iPhone 15 Pro Max with no defects |
| Website | Website | https://example.com | URL/Blog/Portfolio | Enter website here |
