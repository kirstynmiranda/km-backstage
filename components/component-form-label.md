# Form label and helptext — Component Rules

Purpose: Labels for input fields, registration flows, data entry screens, or any other UI element requiring user input.

## Structure
**[Label]** (optional indicator if applicable)
[Input field with placeholder]
[Help text below field]


## Core rules

* Show "(optional)" next to optional fields, or "(required)" if most fields are optional
* Use inline errors below the field to validate correct input
* Group related fields (e.g., first name + last name on same row)
