# Promo Banners — Component Rules

## Structure
Title + Body + CTA (optional)

## Title
- 1 line. Benefit-first: what's in it for the user?
- Communicate the "what" scannably: is it an offer, feature, or change?
- Inform and enable — don't sound like a seller pushing urgency.
- No end period. No exclamation mark.
- Aim ≤ 32 chars; hard max 45.

## Body text
- 1 line. Additional context only.
- Include: what to do (if anything), who qualifies, key constraint (timeframe, eligibility).
- If time-limited, include end date when possible ("until 28 Dec", not "soon").
- If conditional, say it briefly ("Selected items", "For orders over €X").
- Use "you" when instructions are needed.
- Period only if 2 sentences; otherwise no end punctuation.
- Aim ≤ 40 chars; hard max 55.

## CTA (optional)
- Use only when there's a clear next step.
- 1–3 words, verb-first, specific.
- Avoid generic CTAs: "Learn more", "Continue", "Click here".
- CTA verb does not need to match the title (unlike dialogs).
- Aim ≤ 12 chars; hard max 18.
- Omit entirely if purely informational and title + body fully explains the takeaway.

## ✅ / ❌ Examples

| Scenario | ✅ Good | ❌ Bad | Why |
|----------|---------|--------|-----|
| Offer | Title: "Save on shipping this week" / Body: "Get 20% off on selected orders until 28 Dec." / CTA: "Claim deal" | Title: "Special promotion!!!" / Body: "Hurry up and don't miss out on our amazing shipping deal." / CTA: "Click here" | ✅ Benefit-first + constraint + end date + specific CTA. ❌ Vague, hypey, missing details, generic CTA. |
| Feature launch | Title: "New: Bundle items in one order" / Body: "Save on shipping when you buy more from the same seller." | Title: "Bundles" / Body: "We added a new functionality for optimized purchasing." / CTA: "Continue" | ✅ Names what's new + user value. ❌ Too vague, jargony, CTA doesn't reflect action. |
